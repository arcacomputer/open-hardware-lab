# Security policy

Do not open a public issue for vulnerabilities that could expose credentials, personal data, hardware identifiers or unsafe diagnostic execution.

Send a concise report to [ohl@arca.computer](mailto:ohl@arca.computer?subject=Open%20Hardware%20Lab%20security). Include affected files or versions, impact and reproduction details. Do not include real credentials or unrelated personal data.

The website links to a Stripe-hosted Payment Link for voluntary support. The site does not collect or store card details, include Stripe secret keys, or process payments in its own code. Report unexpected payment destinations, altered support terms or suspicious checkout behavior immediately. The project does not currently publish a hardware-probe executable; that security surface will receive a dedicated policy before release.
