# Security policy

Do not open a public issue for vulnerabilities that could expose credentials, personal data, hardware identifiers or unsafe diagnostic execution.

Send a concise report to [ohl@arca.computer](mailto:ohl@arca.computer?subject=Open%20Hardware%20Lab%20security). Include affected files or versions, impact and reproduction details. Do not include real credentials or unrelated personal data.

This project does not currently publish a hardware-probe executable and does not accept payments. Those security surfaces will receive dedicated policies before activation.
