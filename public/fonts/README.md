# Website fonts

Locally hosted Latin subsets from Fontsource, used under the SIL Open Font License.

- Archivo variable, weights 100–900: `@fontsource-variable/archivo` 5.3.0. See `Archivo-LICENSE.txt`.
- IBM Plex Mono, regular 400: `@fontsource/ibm-plex-mono` 5.3.0. See `IBM-Plex-Mono-LICENSE.txt`.

No third-party font requests are made. Archivo is preloaded; both families use `font-display: swap`.
