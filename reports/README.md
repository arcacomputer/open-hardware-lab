# Research reports

No hardware research report has been published yet.

Each report will include:

- report ID, unit ID and test-run ID;
- hardware identity, regional SKU, provenance and relationship disclosure;
- test environment and methodology version;
- bounded research question and selection rationale;
- results, failures and limitations;
- privacy-scrubbed evidence links;
- workarounds and retest status;
- upstream issues and pull requests;
- correction history;
- final hardware disposition when known.

A unit may appear in several reports, operating-system runs and research tracks. Later retests link back to the earlier report rather than silently replacing it.
